# StepWise Local Benchmark

This is a small sequential benchmark using deterministic synthetic software-test data. It is not a
clinical accuracy test or internet-scale load test.

| Measurement | Result |
|---|---:|
| Timed runs | 20 |
| Median | 532.21 ms |
| p95 | 714.07 ms |
| Minimum | 323.69 ms |
| Maximum | 752.30 ms |
| Sequential analyses/minute, derived from median | 112.74 |

Method: Direct pipeline call including parsing, charts, and report generation.

Environment: Windows-11-10.0.26200-SP0; Python 3.13.12; processor Intel64 Family 6 Model 197 Stepping 2, GenuineIntel.
